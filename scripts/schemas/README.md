# Vendored CycloneDX validation schemas

Files are from the upstream CycloneDX specification **1.5** tag:
https://github.com/CycloneDX/specification/tree/1.5/schema

- bom-1.5.schema.json
- spdx.schema.json
- jsf-0.82.schema.json

The CycloneDX JSON schema is published under Apache-2.0. Copyright and third-party schema notices remain in the original files. These exact copies permit offline schema validation; release validation does not retrieve schemas from arbitrary BOM URLs. cargo-cyclonedx 0.5.9 supports CycloneDX 1.5, which is deliberately selected for tool/schema compatibility.
